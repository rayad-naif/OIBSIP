Calculator Project

This project is a fully functional, interactive web-based calculator designed to handle basic arithmetic operations with a highly premium user interface. It allows users to perform addition, subtraction, multiplication, and division, while also supporting operator chaining for complex sequential calculations without needing to clear the screen between steps.

The application includes built-in edge case handling to ensure a smooth user experience. For instance, it actively prevents division by zero by displaying a clear error message instead of crashing the application or returning confusing script errors. It also includes functional clear and backspace buttons to easily correct input mistakes.

The user interface is built using modern CSS Grid layout techniques to ensure perfectly aligned and responsive buttons. The design features a luxurious color palette utilizing deep maroons, rich blacks, and elegant gold gradients to give the calculator a highly professional and refined look that matches the IR Solutions branding.

Under the hood, this tool is built entirely from scratch using standard web technologies. The structure is pure HTML5, the styling is handled by CSS3, and the mathematical logic is powered by Vanilla JavaScript. The script relies strictly on secure event listeners and custom conditional logic, completely avoiding the use of the dangerous eval function for maximum security and control.

To use or test this project, simply download the calculator html file and open it in any modern web browser. The application runs entirely on the client side, meaning no server setup, database, or internet connection is needed after the initial download.
