# Login Authentication System

Simple HTML-based login authentication system created for the OIBSIP WebDev Level 2 task.

Files
- `LAS.html` — main page that demonstrates a login form, client-side validation, and a simple client-side authentication flow (for demo purposes only).

How to use
1. Open `LAS.html` in a web browser (double-click the file or serve with a local static server such as VS Code Live Server).
2. Use the form to test the client-side validation and demo authentication flow.

Notes
- This project is HTML-only and does not include a backend. Do NOT use it to protect real credentials.
- Possible improvements: connect to a backend API, move CSS/JS into separate files, add secure password handling (hashing) on the server, and implement proper session management.
