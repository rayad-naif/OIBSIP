IR Solutions Landing Page

A single-page website built for a premium app development agency using a Maroon, Gold, and Black color palette.

Features

The site features a responsive layout that easily adapts to desktop, tablet, and mobile screens. It includes an interactive mobile dropdown menu and a sticky navigation bar for easy browsing. The design relies on a pure CSS and font-based custom logo, enhanced with UI effects like hover transitions, gradients, and soft shadows.

Technology Stack

This project was developed using core web technologies, specifically HTML5, CSS3, and Vanilla JavaScript. It also integrates Google Fonts for typography, using Playfair Display and Inter, alongside FontAwesome for standard UI icons.

Setup Instructions

To view this project, simply download or clone the repository files to your local machine. Once downloaded, open the index.html file in any modern web browser. There are no build tools, package managers, or external dependencies required to run the site.
