Rayad Farooqi - Personal Portfolio

This repository contains the source code for my personal digital portfolio and resume. It is designed as a single-page, fully responsive website with a modern dark theme to showcase my professional background in full-stack web development, CRM ecosystem architecture, and API integrations.

The portfolio serves as a comprehensive digital resume. It translates complex professional experience, technical skills, and project links into an easy-to-navigate, visually appealing format for potential clients and employers.

The website includes several key features. It has a responsive fluid layout that adapts seamlessly to desktop, tablet, and mobile devices. A sticky navigation bar provides smooth scrolling and includes a mobile-friendly menu. The hero section features a professional portrait and a clear value proposition. Professional roles and dates are laid out in a vertical experience timeline. Proficiency in CRMs, automation, and web technologies is highlighted through a skills matrix using visual progress bars. A dedicated project gallery displays recent SaaS, agency, and web development projects with direct links. Finally, a contact interface provides direct contact details and a message form.

This project is built focusing on core web technologies to ensure fast load times and easy maintenance. It uses HTML5 for semantic structure and CSS3 for all styling, animations, and responsive breakpoints without relying on CSS frameworks. Vanilla JavaScript handles the mobile navigation toggle functionality. Google Fonts and FontAwesome provide clean typography and lightweight vector icons.
