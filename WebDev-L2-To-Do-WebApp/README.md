# To-Do Web App

A simple To-Do web application created for the OIBSIP WebDev Level 2 task.

Files
- `To-Do-Web-App.html` — the complete single-file HTML app implementing task creation, removal, and status toggling.

How to use
1. Open `To-Do-Web-App.html` in a web browser (double-click the file or open via a local static server).
2. Add tasks, mark them done, and remove them. Check localStorage in your browser to see persisted tasks (if implemented).

Notes
- This is an HTML-only project. Consider adding separation of CSS/JS files or adding backend-sync as enhancements.
