Temperature Converter

This project is a fast and interactive web-based temperature converter. It allows users to input a temperature value in Celsius, Fahrenheit, or Kelvin and instantly see the converted values for the other two units simultaneously.

The application includes strict real-time input validation. It prevents users from submitting blank or non-numeric values and includes scientific edge-case handling to reject any temperatures that fall below absolute zero. If an invalid input is detected, a clear error message is displayed to guide the user.

The user interface features a modern dark theme with deep slate and tech blue accents, designed to be fully responsive across mobile, tablet, and desktop devices. The layout ensures that all text and dropdown selectors fit perfectly without overflowing, providing a seamless user experience.

This tool was built entirely from scratch using standard web technologies. The structure is built with HTML5, the styling and responsive design are handled by CSS3 using modern grid layouts, and the conversion logic and error handling are powered by Vanilla JavaScript. No external libraries or frameworks are required.

To use or test this project, simply download the converter html file and open it in any modern web browser. The application runs entirely on the client side, meaning no server setup, database, or internet connection is needed after the initial download.
