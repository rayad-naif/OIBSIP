# Nikola Tesla — Tribute Page

A single-page, responsive tribute website showcasing the life, inventions, and legacy of Nikola Tesla.

Files
- `NikolaTeslaTributePage.html` — the full HTML file for the tribute page (single-file web app).
- `Readme.md` — additional project documentation and technical notes (kept for historical/technical detail).

How to use
1. Open `NikolaTeslaTributePage.html` in a modern web browser (double-click the file or serve from a static file server).
2. Navigate the page to view biography sections, images, and timeline content.

Technology
- HTML5, CSS3, Vanilla JavaScript

Notes
- The folder also contains a `Readme.md` with extended technical documentation and feature checklists; that file contains additional implementation details (cryptography notes and SPA routing) that may be out of place for a simple tribute page — review and consolidate into this README if desired.
